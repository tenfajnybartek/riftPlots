## Prompt — baner

```text
Use case: ads-marketing
Asset type: wide 3:1 GitHub README hero banner for the Minecraft city property plugin riftPlots.
Primary request: an exceptionally polished illustrated project banner with the exact large wordmark "riftPlots" clearly legible on the left, and a detailed isometric voxel city block on the right.
Scene/backdrop: deep midnight navy background, very subtle architectural grid and restrained cyan particles.
Subject: compact beautiful Minecraft-inspired city of townhouses, a shop, trees and a small plaza, on a floating square plot tile edged with luminous cyan parcel boundaries; a subtle vertical blue rift of light behind the city.
Style/medium: premium voxel 3D editorial illustration with crisp edges, clean art direction, dramatic but restrained lighting; intended as an original developer project identity.
Composition: extremely wide landscape 3:1, generous safe margins; large white riftPlots wordmark taking the left half and city illustration on the right. The small geometric emblem above the wordmark combines a voxel house with a cyan rift. No small secondary copy.
Color palette: match the plugin's #00c6ff to #0072ff gradient, white lettering, dark navy, small warm window lights.
Text (verbatim): "riftPlots" (lowercase r, uppercase P).
Constraints: only this one word of text, exact spelling; no badges, no Minecraft logo, no UI, no screenshot claims, no watermark; illustration stays inside the canvas; publication quality.
```
